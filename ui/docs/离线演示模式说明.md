# 离线演示模式说明

> 一句话：小程序打开即用，**不需要 Python、不需要后端、不需要任何电脑配置**。连不上本机引擎时自动切换到内置的真实结果，界面与交互全部可用。

---

## 一、为什么需要它

微信小程序里跑不了 Python。原来的架构是：

```
小程序 → http://127.0.0.1:8765 → 本机 Python 后端 → 训练引擎
```

只要对方没启动后端、换了台电脑、或没装 Python，就会报「无法连接本机后端」。这对只负责 UI、只想看界面效果的人很不友好。

离线演示模式把「连接失败」从错误变成一个自动降级：小程序内置了一批**从真实工作区抓取的响应快照**，探测不到本机后端时用这些快照喂给页面，渲染逻辑一行都不用改。

---

## 二、怎么用（零配置）

1. 用微信开发者工具打开仓库（项目根配置已指向 `ui/miniprogram/`）。
2. 编译。页面启动时会花约 2.5 秒探测本机 `127.0.0.1:8765`：
   - **探测失败**（绝大多数情况）→ 进入演示模式，顶部出现靛蓝色「演示模式 · 内置真实结果」标识。
   - **探测成功**（你本机开着后端）→ 正常连接真实引擎。
3. 演示模式下所有 tab、表单、结果、图表、记录都能点、能看。

### 手动切换

顶部模式条右侧有切换按钮：

- 「用本机引擎」：强制连真实后端（需在开发者工具勾选「不校验合法域名」）。
- 「用演示数据」：强制回到演示模式。

## 三、演示模式能做什么 / 不能做什么

| 能力 | 演示模式 | 说明 |
|---|---|---|
| 浏览全部界面、三个 tab、六个任务表单 | ✅ | 完全可用 |
| 查看历史实验、结果详情、loss 曲线、图表 | ✅ | 内置 97 条真实实验记录 + 真实详情 |
| 查看数据集列表与预览 | ✅ | 8 个数据集，含 AI4I 真实预览 |
| 查看大模型训练结果 | ✅ | 内置 5 条真实 PyTRIO LoRA 训练结果 |
| 点「开始训练 / 参数搜索 / 大模型训练」 | ✅（回放） | 2.5 秒模拟进度后，返回一个预置的真实结果并自动打开 |
| 真正跑 LightGBM / Optuna / PyTRIO 计算 | ❌ | 需要本机引擎或云端后端，见下 |
| 上传自己的 CSV 并训练 | ❌ | 需要真实后端解析 |

**关键点**：演示模式的「训练」是回放预置结果，用于展示交互闭环；不会真的消耗算力或 PyTRIO 配额。

## 四、数据从哪里来

`ui/miniprogram/demo-data.js`（约 215 KB）由一次性脚本从真实工作区接口响应抓取生成，包含 35 个接口的响应快照：

- `/api/dashboard`、`/api/datasets`、`/api/runs`、`/api/jobs`、`/api/loops`
- 一条完整 EXP 实验的详情 / charts / trials
- 一条完整 IND 工业实验的详情 / charts
- 5 条真实 LLM 微调结果详情
- 8 个数据集的预览
- 一条 job 详情与日志

字段格式与后端逐字段一致，因此 `view.js` / `charts.js` 的渲染逻辑完全不用改。

## 六、如果要真正训练

演示模式之外有两条路（详见根目录 `README.md`）：

1. **本机引擎**：在 `algorithm/` 下启动后端，小程序勾「不校验合法域名」后连 `127.0.0.1:8765`。
2. **后端上云**：把 Python 后端部署成公网 HTTPS 服务，小程序填公网地址，任何设备联网都能真训练（尚未实施）。
