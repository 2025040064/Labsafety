# RAC-HPO 移植实施记录

将 RAC-HPO 9badeed 的无界面 Python 服务接入 Labsafety 原生微信小程序。七个入口覆盖数据、训练、优化、比较、日志、离线闭环和工业训练。

工作区单实例写入。训练进程独立运行，SQLite 保存任务状态和成员授权。云端使用微信登录凭证换取服务端会话，首位管理员由部署配置指定。现有数据和实验复制到独立、未跟踪的目录。

验收顺序：数据校验 → 后端真实训练与搜索 → 小程序联调 → 云存储及身份验收。真实数据上传、发布和费用需另行确认。

2026-11-09 本地验收：复制 966 个文件，约 284 MiB（另有两个 SQLite 数据库），校验通过并重载了一个历史 LightGBM 模型。小程序请求层真实运行钢铁审计、训练、随机搜索、AI4I 分类、取消、比较和历史导出。离线会话权限及门禁相关测试通过，工作区重启时任务状态标为中断。WXML、WXSS 与 JavaScript 检查通过。

联调限制：开发者工具要求重新登录，模拟器交互未验收。Docker 引擎不可用，镜像尚未构建验证。云环境、微信登录、真实成员、持久存储与真机尚待验证。
